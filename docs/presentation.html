The Problem

AI dev workflows are fragmented

⚠

Scattered Prompts

Prompts live in random files, clipboard, and chat history. No versioning, no variables, no organization.

🔄

Session Chaos

Dozens of Claude sessions across terminals. No way to track which project, directory, or profile each belongs to.

⏰

Manual Everything

Recurring tasks require manual execution. No scheduling, no notifications, no process oversight.

The Solution

One dashboard to orchestrate it all

Personal AI OS gives you a unified web interface to manage prompts, sessions, scheduled tasks, profiles, and terminals — all backed by a local SQLite database with zero cloud dependencies.

Platform Features

Everything connected

⏱

Task Scheduler

Cron-based and one-shot tasks. Claude CLI execution with token/cost tracking. Run history and enable/disable toggle.

👤

Profile Manager

Auto-discovery of Claude profiles. Per-profile CLAUDE.md, settings, and skills. Login terminal per profile.

🔔

Notifications

Real-time WebSocket alerts. Claude hook integration for stop, idle, and task events. Per-profile hook toggle.

⌘

Command Center

Quick-access command palette for fast navigation and actions across the entire workspace.

🖥

Process Monitor

Scan and kill orphaned Claude processes. Auto-cleanup on server startup. Bulk or per-PID management.

🌐

LAN Mode

Self-signed HTTPS for secure context. Mobile access with voice input. Auto-detects LAN IP.
